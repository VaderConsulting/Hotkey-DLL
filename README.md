# Hotkey DLL

VB6 ActiveX DLL (`Hotkey.dll`, project Hotkey class) exposing `cRegHotkey` for system-wide hotkey register/unregister via `RegisterHotKey` / subclassing, with named hotkey atoms and a `HotKeyPress` event. Companion to the Hotkeys demo tree.

**Source last updated:** 2026-08-27 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** ActiveX DLL
